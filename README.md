# VectaVoIP A2BillingPlus

VectaVoIP A2BillingPlus is a modernization fork of A2Billing for VoIP billing,
rating, customer management, and future provider automation.

## Install

See [install/README.md](install/README.md) for sandbox and production install guides.

See [docs/module-architecture.md](docs/module-architecture.md) for the current
module boundaries and extension pattern.

See [docs/openapi.yaml](docs/openapi.yaml) for the current v1 REST API contract.

See [docs/billing-rating-reporting.md](docs/billing-rating-reporting.md) for the
new rating and reporting regression rules.

Use the web installer at:

```text
http://localhost:8080/install.php
```
